# 🚀 React useState Counter Application

A modern and visually appealing Counter Application built with **React** using the **useState Hook**. This project demonstrates React state management while showcasing a premium UI with glassmorphism, a futuristic design, and dynamic user interactions.

## 🌐 Live Demo




## ✨ Features

- ⚛️ Built with React Functional Components
- 🔄 State Management using the `useState` Hook
- ➕ Increment Counter
- ➖ Decrement Counter
- 🔄 Reset Counter
- 🚫 Prevents Counter from Going Below Zero
- 🎯 Dynamic Status Messages
- 🌌 Full-Screen HD Background
- 🪟 Glassmorphism UI Design
- 💡 Neon Glow Effects
- 🎨 Futuristic Typography
- 📱 Fully Responsive Layout
- ⚡ Instant UI Updates

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/your-username/counter-app.git
```

### Navigate to the Project

```bash
cd counter-app
```

### Install Dependencies

```bash
npm install
```

### Start the Development Server

```bash
npm run dev
```

Open your browser and visit:

```
http://localhost:5173
```

## 🎯 Expected Behavior

| Action | Result |
|---------|--------|
| Increment | Increases the counter by 1 |
| Decrement | Decreases the counter by 1 |
| Reset | Resets the counter to 0 |
| Counter at 0 | Displays "Minimum Limit" message |
